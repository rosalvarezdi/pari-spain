SEÑALES DE RIESGO — PERSPECTIVA REGISTRAL
Affordable Housing Act: riesgo de intromisión en derechos reales e hipoteca
Propuesta legislativa prevista finales 2026 con marco para delimitar zonas de tensión residencial. Naturaleza jurídica (reglamento vs. directiva) sin determinar — si es reglamento, aplicación directa sin margen nacional. Riesgo: mecanismos que intervengan sobre la propiedad y la hipoteca, invadiendo la esfera del sistema registral español.
Iniciativa alquiler corta duración: impacto sobre el sistema NRUA ya implantado
España tiene operativo desde julio 2025 el NRUA gestionado por los Registros de la Propiedad (RD 1312/2024, Ventanilla Única Digital). Si la nueva iniciativa altera la gobernanza de datos o la arquitectura de registro, puede desestabilizar o solaparse con el sistema ya en funcionamiento, generando duplicidad normativa o conflicto competencial.
Informe HOUS en Pleno (marzo 2026): debate sobre zonas tensionadas
La Comisión HOUS aprobó su informe el 9 de febrero de 2026 (23-6-4) con más de 1.000 enmiendas. Votación en pleno pendiente. España es el único país con ley orgánica integral de vivienda, lo que la convierte en referencia y objeto de atención regulatoria europea. Tinagli (HOUS) ya destacó esta singularidad.
Desplazamiento narrativo: de "mercado" a "derecho humano"
El framing ha migrado de "asequibilidad económica" a "derecho humano" y "emergencia habitacional". El Comisario Jørgensen usa explícitamente el lenguaje de "derecho humano". Cuando la narrativa se establece en estos términos, la presión por instrumentos de intervención vinculantes sobre la propiedad aumenta significativamente a medio plazo.
Oportunidad: el sistema NRUA como buena práctica exportable
La arquitectura del Registro Único de Arrendamientos español, gestionada por el Colegio de Registradores, es un modelo avanzado de implementación del Reglamento (UE) 2024/1028. La estrategia de envío de buenas prácticas debe posicionar este sistema como referencia para la Affordable Housing Act, influyendo en que no altere lo ya construido.

POSICIÓN DE LOS REGISTRADORES

No se ha localizado una posición pública formal y explícita del Colegio de Registradores sobre el Plan Europeo de Vivienda Asequible como conjunto. La posición institucional se infiere de dos vectores:


Vector 1 — Implementación normativa: El Colegio de Registradores es el gestor operativo del sistema NRUA. Su sede electrónica es el canal obligatorio de presentación del modelo informativo anual (Orden VAU/1560/2025, modelo XBRL). Tienen interés institucional en que las nuevas iniciativas sean coherentes con la arquitectura ya desplegada y no la dupliquen.


Vector 2 — Preocupación de fondo: El riesgo es que la Affordable Housing Act o la iniciativa de alquileres de corta duración (a) intervengan en el derecho de propiedad y derechos reales como la hipoteca; (b) alteren el sistema registral implantado; o (c) creen duplicidades con registros autonómicos que marginen al Registro de la Propiedad como infraestructura de referencia.


→ Acción recomendada: activar canal directo con el Colegio de Registradores para obtener una posición formal articulada antes del pleno del PE de marzo 2026.

Qué hace este archivo

Es una aplicación standalone: funciona offline, sin servidor ni instalación. Abre el .html en cualquier navegador y el PARI está listo. Puedes mandarlo por email, guardarlo en OneDrive o compartirlo directamente con un cliente.

Todo — CSS, HTML y JavaScript — está en un único archivo. Cualquier cambio con un editor de texto (VS Code, Notepad++, incluso el Bloc de Notas) se refleja al recargar la página en el navegador.

Añadir un nuevo caso (issue)

Busca en el código la sección marcada con el comentario CASOS — añade aquí nuevos issues y añade un objeto al array const CASES:

// Índice 0 = caso que se carga al abrir el archivo { name: "Nombre del issue", scores: { mai: 55, // Media Attention (0–100) pai: 72, // Political Activity (0–100) peso 30% spi: 60, // Stakeholder Pressure (0–100) pubai: 45, // Public Attention (0–100) nsi: 68 // Narrative Shift (0–100) }, velocity: +5, // Δ vs. período anterior (negativo si baja) analyst: "Tu nombre", date: "Abril 2026" },

Luego añade su botón en el header — busca header-btns en el HTML:

<button class="demo-btn" onclick="loadCase(N)">Nombre del caso</button> <!-- N = posición en el array (0, 1, 2...) -->

Cambiar los pesos de los pilares

Busca const PILLARS = [. Cada pilar tiene un campo weight. Los cinco pesos deben sumar exactamente 1.0:

{ id:"mai", weight:0.20 }, // ← sube si el issue es muy mediático { id:"pai", weight:0.30 }, // ← el más predictivo de acción regulatoria { id:"spi", weight:0.20 }, { id:"pubai", weight:0.15 }, // ← sube para issues de consumo / reputación { id:"nsi", weight:0.15 } // ← sube si el framing está cambiando rápido

Personalizar indicadores de un pilar

Dentro de cada pilar hay un array indicators. Cambia label y desc sin tocar el id:

indicators: [ { id: "pai_parl", // no cambies el id label: "Preguntas parlamentarias", desc: "Interpelaciones en Congreso, Senado y PE" }, ... ]

Cambiar colores

En :root al inicio del CSS están las variables globales. Para cambiar el acento dorado o el fondo:

:root { --gold: #C8A97E; // color de acento principal --bg: #080808; // fondo general --surface: #111; // fondo de modales --border: rgba(255,255,255,0.07); // bordes }

Cada pilar tiene su propio color. Búscalo en PILLARS:

{ id:"mai", color:"#C8A97E", ... } // cambia el hex

Editar la pestaña ANÁLISIS

El análisis cualitativo está en el bloque HTML con id="tab-analysis". Cada señal de riesgo es una tarjeta — cámbiala directamente en el HTML:

<div class="flag high"> <!-- high · med · low --> <div class="flag-dot"></div> <div> <div class="flag-title">Título del riesgo</div> <div class="flag-text">Descripción...</div> </div> </div>

El número y color del PARI en la cabecera de esta pestaña se actualiza automáticamente con los sliders — no hace falta tocarlo.
